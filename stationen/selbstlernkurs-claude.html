2

Prompt 1: Das Infoblatt

ca. 4 Minuten

Ein guter Prompt besteht aus drei Zutaten. Mehr brauchst du nicht:

Wer bin ich?Was soll entstehen?Womit soll Claude arbeiten?

Den Fachhintergrund schreibst du in Stichpunkten, wie du ihn sowieso im Kopf hast. Claude formuliert daraus die Sprache für die Klasse.

So kann das Ergebnis aussehen (Beispiel)

Passt etwas nicht? Schreibe einfach im selben Chat weiter, zum Beispiel „Kürze die Definitionen“. Du musst nicht neu anfangen.

3

Prompt 2: Vom Arbeitsblatt zur interaktiven Übung

ca. 5 Minuten
  1. Klicke im Chat auf das Plus und hänge dein Arbeitsblatt an. Nimm ein PDF oder ein Foto. Eine Word-Datei speicherst du vorher als PDF.
  2. Bleibe im selben Chat, damit Claude das Infoblatt von eben kennt, und sende diesen Prompt:
Was soll entstehen?In welcher Form?Womit arbeiten?

Probiere die Übung selbst aus

Du bist jetzt Schülerin oder Schüler. Ziehe oder tippe die Begriffe auf den Eisberg und löse die beiden anderen Aufgaben.

Beispiel-Ergebnis: interaktive Übung

So speicherst du die Übung

  1. Claude gibt den Code im Chat aus. Kopiere ihn mit dem Kopier-Symbol am Codeblock.
  2. Öffne den Editor (Notepad), füge den Code ein.
  3. Wähle Speichern unter, Dateiname uebung.html, Dateityp „Alle Dateien“, Kodierung UTF-8.
  4. Doppelklick auf die Datei öffnet sie im Browser. Funktioniert die Übung, kannst du sie an deine Klasse weitergeben.

5

Feinschliff mit kurzen Folge-Prompts

ca. 3 Minuten

Das Ergebnis ist selten auf Anhieb perfekt, und das ist gewollt. Du verbesserst es mit einem Satz. Klicke zum Kopieren:

An die Klasse bringen

Gib die HTML-Datei über euer Schulsystem weiter (Lernplattform, Teams, Mail) oder lege sie online ab. Liegt sie unter einem Link, erzeugt das Fobizz-Tool QR-Code (Tools, „Inhalte teilen“) einen Aushang für die Klasse.

In der Teststation liegen Übung und Rallye außerdem fertig als Übungen im Ordner „Selbstlernkurs Claude“. Dort gibst du sie per Link oder QR-Code direkt an eine Klasse.
