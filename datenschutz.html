Was wird verarbeitet?

Die Teststation sendet keine Eingaben, Ergebnisse oder Kennungen an einen Server. Es gibt keine Konten, keine Namen, keine Datenbank, keine Analyse- oder Werbedienste und keine von Dritten geladenen Schriftarten oder Skripte.

Auf dem Gerät der Schüler/-innen speichert der Browser (localStorage) nur: zuletzt genutzten Klassencode, Teamnummer und das beste Ergebnis einer Übung. Die Ergebnisse werden der Lehrkraft nur mündlich bzw. als Ergebniscode (Teamnummer, Punkte, Züge, Zeit) gezeigt; die Lehrkraft-Rangliste wird nicht gespeichert.

Hosting

Die Seiten werden über GitHub Pages ausgeliefert. Dabei verarbeitet GitHub technisch bedingt IP-Adressen und Zugriffsdaten (Server-Logs) – [mit DSB prüfen].

Löschung

Lokal gespeicherte Angaben können über die Browser-Einstellungen („Websitedaten löschen“) entfernt werden.

Rechte

Auskunft, Berichtigung, Löschung, Einschränkung, Widerspruch; Beschwerde beim Bayerischen Landesbeauftragten für den Datenschutz.
