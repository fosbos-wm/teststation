Übung verschlüsseln (Zugangscode)

Dieses Werkzeug läuft nur in deinem Browser. Die Übung und der Code werden nirgends hingeschickt.

  1. Die Klartext-Datei der Übung wählen (z. B. resilienz-sinn-suchen-sinn-finden.json).
  2. Einen Code festlegen oder einen Zufallscode erzeugen. Den Code aufschreiben, er lässt sich nicht wiederherstellen.
  3. „Verschlüsseln“ drücken. Die heruntergeladene Datei ersetzt die Datei im Ordner inhalte im Repo.

Wichtig: Die Klartext-Datei nicht ins Repo legen. Sie bleibt nur bei dir. Im Repo liegt nur die verschlüsselte Datei. Wer den Link hat, aber den Code nicht, kann die Übung nicht starten und den Inhalt auch nicht lesen.
